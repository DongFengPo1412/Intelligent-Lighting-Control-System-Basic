## ハードウェアと接続

| 部品・接続 | 試作機での用途と確認事項 |
| :--- | :--- |
| ASRPROボード | 参加者説明ではASRPRO v2.0。マイクと外付けスピーカーを使い、Flash容量は実物で確認。 |
| WS2812B 4枚 | 各8×8、計256灯。論理配置は左上・右上・左下・右下。DOUTを次のDINへ接続し、内部配線も実物確認。 |
| SDK論理Pin 2 | LEDデータ出力。論理番号はチップ端子番号・コネクタ順とは異なります。 |
| SDK論理Pin 13/14 | `SECOND_FUNCTION`でUART TX/RX。HM-10のRX/TXへ交差接続し、信号GNDを共有。 |
| HM-10 | スマートフォンBLEとUARTの橋渡し。裸モジュール／基板付きの電源・信号仕様を確認し、一律5V接続とはしません。 |
| PCのUSB | 試作機の給電方法。輝度値だけではUSB容量・電圧降下・余裕は分かりません。 |
| スピーカー | ボードの出力端子へ接続。アンプはボード機能で、実物のインピーダンス・定格を確認。 |
| 木製収納箱 | 購入箱、透明蓋、USB切欠き。蓋材質と内部レベル変換は未確認。 |

接続は実ボード資料に従います。全体電流の実測予算は提供していません。

## ツール・音声リソース・書込み

1. ASRPRO対応の天問Blockと適合USBシリアルドライバを導入し、コア／開発ボード、Flash容量、ポートを確認します。
2. `.hd`を選び、XMLはグラフィカル、C++はコードモードで開きます。`asr.h`、`setup.h`、`myLib/asr_ws2812.h`はプラットフォーム側にあり、独立CMake、PlatformIO、Arduino工程ではありません。
3. 起動語、ID、応答を確認し、変更後は音声・モデル資源を生成します。これは設定作業で、独自音響モデル学習とは区別します。
4. 音楽は選択応答を固定断片に差し替えます。元デモ音声と生成資源は全て同梱していません。
5. 既知のコード問題を確認してビルドし、実ボード・Flashに合う設定で書き込みます。過去の「2M」という説明だけで全ボードを判断しません。
6. 再起動後、起動・音声・単一効果・シリアル入力・終了を個別確認します。本整理では実機再試験をしておらず、ビルドログと変更を記録します。

<a id="operation"></a>

## 工程別の操作

### 音声照明と表情

選択工程の起動語を言い、固定応答後に設定命令を言います。「最终版本」は「显示笑脸」「显示哭脸」「变脸」「显示桌宠」「关闭灯光」です。「功能二／功能2」は別の照明語彙を使い、全工程の語彙を混ぜません。

SDK手引きの無命令時既定終了は15秒で、ツール版に依存します。純音声プログラムはBluetooth接続不要です。AEC対応だけで全アニメ・音楽の任意中断は確認できません。

### スマートフォンのスネーク操作

1. ゲーム版を用い、HM-10 UARTを115200 bpsに合わせてからスマートフォンのBLEへ接続します。
2. 元デモのBlinker 5ボタンを使い、主制御側へ大文字1字の`E`、`W`、`S`、`A`、`D`が届くことを確認します。App設定は未保存なので、必要ならBLEシリアルツールで文字を試してからボタンへ対応させます。余分なデータや自動連打は制御に影響します。
3. 停止中の`E`で開始し、`W/S/A/D`で上・下・左・右へ移動します。実行中の`E`は無視されます。
4. 自身衝突で赤点滅後、UARTへ`Game Over! Your Score: ...`を出します。スマートフォンの文字表示は受信画面次第で、このコードにLED数字得点と音声開始はありません。

### スマートフォン点灯試験

`蓝牙点灯.hd`は9600 bps、64灯、`readString()`による`on`／`off`の完全一致を使います。ゲームの1字命令と異なる複数文字の文字列です。改行・タイムアウトが一致に影響するため、ゲームの設定をそのまま使いません。

<a id="troubleshooting"></a>

## 再現確認とトラブル対応

| 現象 | 最初に確認する項目 |
| :--- | :--- |
| 命令に反応しない | 版、起動状態、ID、応答資源とアプリの同時書込み。 |
| 遅延・描画の異常 | 修正版、SDK、線形／分割写像、パネル向きを確認。遅延配列は16ビットに修正済み。 |
| 遅延・描画の異常 | 修正版、SDK、線形／分割写像、パネル向きを確認。遅延配列は16ビットに修正済み。 |
| BLE接続後も無反応 | UART透過設定、速度、TX/RX、大小文字、実際のファームウェア。 |
| on/offが無反応 | ゲーム版の誤使用、改行・余分な文字。 |
| アニメ・音楽が止まらない | 長いループと遅延。AEC機能だけで終了処理を代替しません。 |
| LEDに得点が出ない | 保存版はシリアルのみで、数字字模とデモ版処理が未保存。 |
| 満盤・連続入力 | 最新値スロット方針と対象の原子操作を確認。全入力を保存する場合は別途FIFOが必要。 |

全機能の再現試験済み統一パッケージとはしていません。追加・修正は別コミットとし、ビルド環境の記録後に実機試験を行います。
