## 硬件与接线

| 部件／接口 | 样机用途与核对事项 |
| :--- | :--- |
| ASRPRO 开发板 | 参与者描述为 ASRPRO v2.0，使用麦克风与外接扬声器；具体 Flash 容量需按实际板卡选型。 |
| 四块 WS2812B | 8×8 面板共 256 灯，逻辑排列为左上、右上、左下、右下。逐板 DOUT 接下板 DIN，按实物确认各板内部走线。 |
| SDK 逻辑 Pin 2 | 程序的灯板数据输出。逻辑编号不能直接当作芯片封装脚号或排针序号。 |
| SDK 逻辑 Pin 13 / 14 | `SECOND_FUNCTION` 配置的 UART TX / RX，分别交叉连接 HM-10 的 RX / TX，信号共地。 |
| HM-10 | 手机 BLE 与主控 UART 的桥接；确认具体裸模块／带底板版本的电源与信号电平，不能一概写为 VCC 接 5V。 |
| 电脑 USB | 样机的实际供电方式；代码亮度数值不能证明 USB 电流容量、压降或稳定余量。 |
| 扬声器 | 接开发板扬声器接口，功放能力属于板卡；扬声器阻抗与额定功率需核对实物。 |
| 木质收纳盒 | 购入盒体、透明盖板及 USB 线缺口；透明材质及内部电平转换未确认。 |

硬件连接按实际板卡资料核对。未提供经过实测的整机电流预算。

## 工具链、语音资源与下载

1. 安装天问 Block 的 ASRPRO 支持及与板卡匹配的 USB 串口驱动。检查实际连接的是核心板还是开发板、Flash 容量及下载端口。
2. 打开选定 `.hd`。图形 XML 用图形模式，C++ 内容用代码模式。`asr.h`、`setup.h`、`myLib/asr_ws2812.h` 等由平台提供；本仓库不是独立 CMake、PlatformIO 或 Arduino 构建工程。
3. 核对所选程序的唤醒词、命令 ID 和回复。修改后按工具流程生成模型／语音资源；这属于平台配置，不等于自行训练了新的声学网络。
4. 音乐展示需将指定回复音频替换为准备好的固定片段；原演示音频和生成资源未完整随仓库提供。
5. 检查代码已知问题后编译，选匹配板卡与 Flash 的下载配置。不要因旧文档写过“2M”就默认适用于所有板卡。
6. 下载后重启，分别核对启动、唤醒、单个灯效、串口输入和退出。归档代码未经本轮硬件重测，保留编译日志和实际修改记录。

<a id="operation"></a>

## 分程序操作

### 语音灯效与表情

先说所选工程的唤醒词，收到固定应答后说该工程配置的命令。“最终版本”的命令为“显示笑脸”“显示哭脸”“变脸”“显示桌宠”“关闭灯光”；“功能二／功能2”使用另一组灯效词条。不能混用全部工程的词条。

SDK 手册说明默认无命令退出时间为 15 秒，具体行为需匹配工具版本。蓝牙配对不是纯语音程序的启动条件。芯片支持 AEC 不等于已验证动画或音乐循环中的任意时刻打断。

### 手机与贪吃蛇

1. 使用游戏版本，确认 HM-10 的 UART 速率与主控 115200 bps 配置一致，再从手机连接 BLE 设备。
2. 按原演示配置使用 Blinker 的五个按钮，核对透传到主控的内容分别为大写单字符 `E`、`W`、`S`、`A`、`D`。App 工程配置未随仓库保存，可先用 BLE 串口工具发送这些字符验证链路，再适配按钮；额外载荷和自动重复可能影响控制。
3. 停止状态发送 `E` 开始；`W/S/A/D` 为上／下／左／右。正在游戏时 `E` 被忽略。
4. 自碰撞后显示红闪，再通过 UART 输出 `Game Over! Your Score: ...`。接收端是否显示文本取决于手机界面；该源码没有 LED 数字得分或语音启动路径。

### 手机点灯实验

`蓝牙点灯.hd` 使用 9600 bps、64 灯和 `readString()` 精确比较 `on`／`off`。这些是多字节字符串，不是游戏的单字符协议。发送端的换行和超时会影响匹配；不要套用游戏版本的速率与命令。

<a id="troubleshooting"></a>

## 复现检查与故障排查

| 现象 | 首先检查 |
| :--- | :--- |
| 词条不响应 | 工程版本、唤醒状态、命令 ID、生成资源是否与应用一同下载。 |
| 延时数组编译报窄化 | `uint8_t` 不能容纳 300/500；在修复版本中使用合适类型并重新验证动画。 |
| RGB 图案错位／异常 | 1–16 下标越界、线性与分块映射差异、各面板实际方向。 |
| 手机连接却不能控制 | BLE 透传配置、UART 速率、TX/RX、字符大小写和实际烧录程序。 |
| on/off 无反应 | 检查是否误用了游戏固件，或字符串附带换行／其他字符。 |
| 动画／音乐不能退出 | 长循环和阻塞延时，不能用平台 AEC 功能代替应用退出逻辑检查。 |
| 分数没有显示在点阵 | 归档版只写串口；需补齐对应数字字模和演示版逻辑。 |
| 游戏满盘或快速转向异常 | 食物生成的满盘退出、同一步的多次方向变化及共享状态。 |

本仓库没有声称经过完整复现测试的统一发布包。需要新增或修改代码时，应单独提交、记录编译环境，再开展实机测试。
